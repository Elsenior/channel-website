# Unique Coderz Academy

الموقع الرسمي لقناة **Unique Coderz Academy** على يوتيوب: قناة عربية لتعليم البرمجة وتطوير الويب.

## الصفحات
- `index.html`: الرئيسية
- `courses.html`: جميع الكورسات (80 قائمة تشغيل مرتبة حسب الموضوع والمستوى)
- `roadmap.html`: خريطة التعلم خطوة بخطوة
- `mentorship.html`: جلسات الإرشاد الفردية
- `about.html`: عن القناة وصاحبها

## التقنيات
HTML و CSS، مع ملف JavaScript صغير لعدّاد الزيارات (`js/counter.js` عبر GoatCounter).

## التشغيل
موقع ثابت بالكامل: افتح `index.html` في المتصفح، أو انشره على GitHub Pages.
