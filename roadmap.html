خريطة التعلم

مسار مرتب يأخذك من الصفر حتى أول وظيفة كمطور ويب. أكمل كل خطوة قبل الانتقال إلى التي بعدها، ولا تنسَ أن تطبّق بيدك.

  1. 🧭 تعرّف على المجال

    قبل أن تكتب أي كود، افهم ما هو تطوير الويب وكيف تفكر كمبرمج.

    ▶ كيف أبدأ تعلم الويب؟ ▶ تعاريف مهمة ▶ فروقات مهمة ▶ فكّر ثم اكتب الكود

  2. 🎨 أساسيات HTML و CSS

    تعلّم بناء هيكل الصفحة وتنسيقها وجعلها متجاوبة مع كل الشاشات.

    ▶ دورة HTML ▶ دورة CSS ▶ CSS3 ▶ التصميم المتجاوب ▶ CSS Grid ▶ خاصية Position ▶ توسيط العناصر ▶ Bootstrap 4

  3. 🖥️ صمّم مواقع كاملة

    طبّق ما تعلمته في قوالب ومواقع حقيقية. هنا يثبت الفهم.

    ▶ مشروع HTML5 و CSS3 الكبير ▶ مشروع مع Git و GitHub ▶ قالب متجاوب ▶ قالب مع Sass ▶ سلسلة التصميم من الصفر

  4. ⚡ لغة جافاسكربت

    اجعل صفحاتك تفاعلية. ركّز على فهم الأساسيات جيداً لأن كل ما بعدها يعتمد عليها.

    ▶ كورس جافاسكربت الكامل ▶ أمثلة وتطبيقات ▶ البرمجة الكائنية OOP ▶ LocalStorage ▶ ما ناتج هذا الكود؟ ▶ jQuery (اختياري)

  5. 🛠️ مشاريع وحل مشكلات

    ابنِ مشاريع لمعرض أعمالك ودرّب عقلك على حل المسائل.

    ▶ مشاريع جافاسكربت ▶ تطبيق GitHub ▶ تطبيق الوصفات ▶ لعبة بـ OOP ▶ متجر وسلة مشتريات ▶ حل المشكلات بجافاسكربت ▶ مسائل Codeforces

  6. ⚛️ React والأدوات الحديثة

    تعلّم الأدوات التي تطلبها الشركات اليوم لبناء تطبيقات كبيرة وسريعة.

    ▶ TypeScript ▶ React الكامل ▶ تطبيق المهام ▶ تطبيق الطقس ▶ Redux الكامل ▶ Redux Toolkit ▶ Next.js ▶ تطبيق MERN

  7. 💼 الاستعداد لسوق العمل

    جهّز نفسك للمقابلات وتعرّف على طريقة الوصول إلى الشركات والحصول على أول وظيفة.

    ▶ دورة التأهيل لسوق العمل ▶ أسئلة مقابلات Front End ▶ طريقك للشركات
